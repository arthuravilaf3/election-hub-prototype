# Election Hub 2026 — protótipo (build)

Site compilado do protótipo de design do Election Hub da DailyWire+.
Este repositório contém **apenas o output do build** — o código-fonte é
privado.

Publicado por GitHub Pages: https://arthuravilaf3.github.io/election-hub-prototype/

renderizar completa.
